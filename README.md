# Birthday Surprise Website

A cute React + Vite birthday page with a date gate, playful "Rak wajed?" interaction, long birthday letter, and floating kisses.

## Run locally
1. Install Node.js (LTS).
2. Extract this folder.
3. Open a terminal inside the folder and run:
   ```bash
   npm install
   npm run dev
   ```
4. Open the local URL Vite prints (usually http://localhost:5173).

## Customize
- Correct birth date is currently `2005-06-15` in `src/main.jsx`.
- The full letter is in the `birthdayMessage` constant in `src/main.jsx`.
- Colors, fonts, layout and animations are in `src/style.css`.

## Build for hosting
Run `npm run build`. Vite creates the production site in the `dist` folder.
